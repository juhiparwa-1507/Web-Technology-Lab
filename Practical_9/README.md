# Practical 9: Git & GitHub

## Aim
To study Git fundamentals and GitHub collaboration.

## Objectives
- Initialize and manage a Git repository.
- Track, stage and commit changes.
- Create and merge branches.
- Push and pull changes using GitHub.
- Understand cloning, pull requests and merge conflicts.

## Technologies Used
- Git
- GitHub
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Project Description
This project demonstrates important Git commands
and provides an interactive commit message demo.

## Commands
- git init
- git status
- git add .
- git commit
- git branch
- git merge
- git push
- git pull
- git clone

## Result
Successfully created a webpage demonstrating Git
and GitHub concepts.
